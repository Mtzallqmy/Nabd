# بنية نَبْض

يُشغّل FastAPI وaiogram داخل عملية واحدة مع إشارة إيقاف موحدة. يفتح وسيط التحديثات جلسة SQLAlchemy لكل تحديث. تحمي معالجات المشاريع الأوامر والأزرار بشرط المحادثة الخاصة ومعرّف المشرف. تُنفّذ قراءة GitHub بعميل HTTPX ويُرمّز اسم الفرع قبل استخدامه في المسار.

تتضمن قاعدة البيانات مستخدمي تيليجرام المرتبطين بالعمليات، ومشاريع GitHub، وسجلًا ذريًا للإضافة والحذف. يفرض فهرس قاعدة البيانات التفرد بحساسية مستقلة عن حالة الأحرف. Alembic مسؤول عن المخطط. يعرض أمر الإعدادات حالة التهيئة الحالية وتُضبط قيمها في متغيرات البيئة.
