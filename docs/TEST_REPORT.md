# تقرير التحقق

تشمل مجموعة الاختبار أوامر تيليجرام عبر طلبات محاكاة، وسلوك GitHub عبر ردود محاكاة، وفحص الجاهزية مع FastAPI، وترحيل مشروع موجود إلى SQLite وPostgreSQL. استخدم `NABD_TEST_POSTGRES_URL` مع قاعدة مؤقتة فارغة لاختبار PostgreSQL. تشغّل GitHub Actions الفحص البرمجي واختبارات الترحيل وفحص الاعتماديات والأسرار وتجربة Docker مع تيليجرام معزولًا عن الشبكة.

اجتاز عميل GitHub طلب قراءة حيًا للمستودع العام `Mtzallqmy/Nabd`. تُسجَّل حالة فحص Docker في صفحة Actions. يحتاج تحقق Telegram وNeon إلى اعتماديات الإنتاج.

التحقق المحلي قبل الرفع: نجح 21 اختبارًا على Python 3.12، بما فيها PostgreSQL 16 محلي وSQLite. نجحت أوامر compileall وRuff وفحص تطابق حزمة التسليم. لم يبلغ pip-audit عن ثغرات معروفة في بيئة التحقق، ولم يجد Gitleaks أسرارًا. تظهر رسالة إهمال توافق TestClient مع HTTPX، مع نجاح اختبار الجاهزية.
