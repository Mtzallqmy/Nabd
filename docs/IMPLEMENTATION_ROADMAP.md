# خريطة التنفيذ

1. النواة. إثبات تشغيل البوت في Railway وقاعدة PostgreSQL على Neon بعد مراجعة CI.
2. المراقبة. جدولة GitHub Actions والإصدارات وفحوص الصحة وسجل المراقبة والإشعارات.
3. البنية التحتية. قراءة Railway وVercel ثم إجراءات تشغيل مقيدة بموافقات.
4. لوحة ويب عربية. مصادقة وعرض المشاريع والتاريخ والإعدادات.
5. التشخيص. تحليل السجلات واقتراح إجراءات تُراجع بشريًا.
6. الإنتاج. قياس الأداء ومراجعة الأمان والتحقق الحي والإصدار.
